# Radish

Radish is a project for interfacing with Daikin/ClimateTalk-style HVAC networks.

## What this project includes

- ESPHome profile for sniffing bus messages and publishing them to MQTT
- Python tooling for decoding and analysis of MQTT messages from the bus
- ESPHome external component for bus sniffing plus network participation features
